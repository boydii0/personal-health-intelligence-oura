# Privacy Policy

**Last updated: August 16, 2026**

Personal Health Intelligence — Oura Integration is a private, single-user application used by its owner to access the owner's own Oura Ring data.

## Data Collected

The application may retrieve Oura data that the user explicitly authorizes through the Oura OAuth2 consent process, including health, sleep, activity, heart-rate, workout, and related Oura metrics.

## How Data Is Used

Retrieved data is used solely for personal health tracking, longitudinal analysis, reporting, and personal research.

## Data Storage

Authorized Oura data is stored in a privately controlled Personal Health Intelligence repository.

The application is not designed as a public or multi-user service.

## Data Sharing

Oura data is not sold.

Oura data is not intentionally shared with advertisers, data brokers, or unrelated third parties.

## Authentication

Authentication is performed using Oura OAuth2.

Authentication credentials, access tokens, refresh tokens, and client secrets are not stored in public repositories.

## Access and Deletion

The sole user controls the stored data and may remove imported data or revoke the application's Oura access.

## Contact

This application is maintained for private personal use.
