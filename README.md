# Personal Health Intelligence — Oura Integration

Personal Health Intelligence is a private, single-user health data integration used to retrieve my own Oura Ring data for personal longitudinal analysis.

The integration connects to the Oura API using OAuth2 and imports authorized health and activity data into my privately controlled Personal Health Intelligence repository.

The application is not offered to other users and is not a commercial product.

Oura data retrieved through this integration is used only for my personal health tracking, trend analysis, and personal research.

No Oura data is sold or publicly shared.
